# خادم زاجل — API

خادم خلفي حقيقي (Node.js + Express) بمصادقة **بريد/كلمة مرور حقيقية**، قاعدة بيانات JSON محفوظة على القرص (`db.json`)، **لوحة تحكم إدارية كاملة**، و**متجر** (محاكاة شراء جاهزة لربطها ببوابة دفع حقيقية).

## 👑 من هو الأدمن (صاحب التطبيق)؟
**أول شخص يسجّل حساب على نسختك من الخادم يصبح تلقائياً أدمن.** لذا أول خطوة بعد النشر: افتح التطبيق أو لوحة التحكم وسجّل حسابك الخاص أولاً، قبل ما تشارك الرابط مع أي أحد.

## التشغيل محلياً
```bash
npm install
npm start
```
الخادم يعمل افتراضياً على `http://localhost:3001`.

## نقاط الوصول (Endpoints)

### المصادقة
| الطريقة | المسار | الوصف |
|---|---|---|
| POST | `/api/auth/register` | `{name, email, password}` → تسجيل حقيقي بكلمة مرور مشفّرة |
| POST | `/api/auth/login` | `{email, password}` → تسجيل دخول حقيقي |
| GET | `/api/me` | بيانات المستخدم الحالي |
| PATCH | `/api/me` | تحديث الأفاتار/النبذة/الهوايات/الفلاتر |

### الحمام والمحادثات
| POST | `/api/pigeons/send` | إرسال حمامة |
| GET | `/api/chats` | قائمة المحادثات |
| POST | `/api/chats/:id/messages` | إرسال رسالة |
| POST | `/api/chats/:id/consent/:type` | تفعيل مكالمة |

### المتجر
| GET | `/api/store/products` | عرض المنتجات (بدون تسجيل دخول) |
| POST | `/api/purchase` | `{productId}` → **شراء محاكى فوري** (بدون بوابة دفع حقيقية بعد) |

⚠️ **مهم قبل الإطلاق التجاري الفعلي**: نقطة `/api/purchase` تمنح المنتج فوراً بدون تحقق دفع حقيقي — مصممة هذي المرحلة كواجهة ومنطق جاهزين فقط. لتفعيل دفع حقيقي، أضف بوابة دفع (Stripe مثلاً) تتحقق من نجاح الدفع أولاً قبل استدعاء منطق المنح الموجود داخل هذي الدالة في `server.js` (الموضع مُعلَّم بتعليق واضح بالكود).

### لوحة تحكم الأدمن (صلاحية أدمن فقط)
| GET | `/api/admin/stats` | إحصائيات شاملة |
| GET | `/api/admin/users` | كل المستخدمين |
| PATCH | `/api/admin/users/:id` | تعديل رصيد/سمعة/حظر/منح اشتراك |
| DELETE | `/api/admin/users/:id` | حذف مستخدم نهائياً |
| GET/PATCH | `/api/admin/config` | تعديل منتجات المتجر وتفعيله/إيقافه |

كل الطلبات المحمية تحتاج ترويسة: `Authorization: Bearer <token>`

## لوحة التحكم (admin.html)
ملف مستقل بواجهة كاملة — تفتحه بالمتصفح، تدخل رابط خادمك وبريد/كلمة مرور حساب الأدمن (أول من سجّل)، وتقدر منها:
- مشاهدة إحصائيات شاملة (مستخدمين، محادثات، رسائل، مشتركين مميزين)
- البحث وتعديل أي مستخدم (سمعة، منح/إلغاء اشتراك مميز، حظر/فك حظر، حذف)
- تعديل منتجات المتجر (الاسم، النوع الممنوح، الكمية، السعر) وتفعيل/إيقاف المتجر بالكامل

## النشر (لجعله متاحاً من الإنترنت)

**Render.com**
1. ارفع هذا المجلد إلى مستودع GitHub
2. من Render: New → Web Service → اربط المستودع
3. Build Command: `npm install` — Start Command: `npm start`
4. أضف متغير بيئة `JWT_SECRET` بقيمة عشوائية قوية

**Railway.app**: نفس الخطوات تقريباً، يكتشف Node.js تلقائياً.

بعد النشر:
1. خذ الرابط الناتج وسجّل حسابك الأول فيه (يصير أدمن تلقائياً)
2. افتح `admin.html` وسجّل دخولك بنفس الحساب لإدارة التطبيق
3. ضع نفس الرابط في تطبيق `زاجل.html` (من "حسابي") لربط الواجهة الرئيسية

## ملاحظات أمان قبل الإنتاج الفعلي
- بدّل `JWT_SECRET` بقيمة سرية قوية عبر متغير بيئة، ولا تتركه بالقيمة الافتراضية
- فعّل بوابة دفع حقيقية (Stripe موصى بها) قبل تفعيل `/api/purchase` تجارياً — راجع التحذير أعلاه
- استبدل `lowdb` بقاعدة بيانات حقيقية (PostgreSQL/MongoDB) عند الحاجة لأداء وتزامن أعلى مع عدد مستخدمين كبير
- أضف Rate limiting وvalidation أعمق، وفعّل HTTPS دائماً (تلقائي على Render/Railway)
- فعّل نسخ احتياطي دوري لملف `db.json` أو انتقل لقاعدة بيانات مُدارة
